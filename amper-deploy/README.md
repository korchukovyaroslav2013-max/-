# Ампер: сайт на Vercel + сервер на Render + база Neon

    amper-deploy/
      frontend/   — сайт (статические файлы) → Vercel
      backend/    — сервер (Node.js) → Render
    База данных: Neon (бесплатный Postgres) — там хранятся каталог, промокоды, заказы, отзывы.

Почему база отдельная: на бесплатном Render диск стирается при каждом перезапуске, а бесплатный Postgres самого Render
удаляется через 30 дней. Neon хранит данные постоянно.

## Шаг 1. База (Neon)
1. Зарегистрируйтесь на neon.tech, создайте проект.
2. Скопируйте строку подключения (Connection string), она начинается с `postgresql://`. Это `DATABASE_URL`.
Таблицу сервер создаст сам.

## Шаг 2. Загрузите папку на GitHub
Создайте репозиторий и положите в него всё содержимое `amper-deploy` (папки `frontend` и `backend`).

## Шаг 3. Сервер на Render
1. Render → New → Web Service → выберите репозиторий.
2. Root Directory: `backend`. Build Command: `npm install`. Start Command: `npm start`. План: Free.
3. Environment Variables:
   - `DATABASE_URL` — строка из Neon
   - `ADMIN_KEY` — придумайте длинный секретный ключ администратора (его вы будете вводить на странице входа)
   - `FRONTEND_ORIGIN` — адрес сайта на Vercel, например `https://amper.vercel.app` (добавите после шага 4; можно несколько через запятую)
4. После деплоя откройте `https://ваш-сервис.onrender.com/api/health`. Должно быть `{"ok":true,"store":"postgres"}`.

## Шаг 4. Сайт на Vercel
1. В файле `frontend/config.js` замените адрес на адрес вашего сервиса Render:
   `window.AMPER_API = "https://ваш-сервис.onrender.com";` и закоммитьте.
2. Vercel → Add New → Project → тот же репозиторий. Root Directory: `frontend`. Framework: Other. Build Command пустой.
3. После деплоя скопируйте адрес сайта и вернитесь на Render: впишите его в `FRONTEND_ORIGIN` (сервис перезапустится).

## Вход администратора
Откройте `https://ваш-сайт.vercel.app/admin-login` и введите `ADMIN_KEY`. После этого в шапке появится кнопка админ-панели.
При первом входе в панель задайте её пароль. Заказы в Excel: в админке, вкладка «Заказы» → «Скачать заказы в Excel»
(или администратору доступен `https://ваш-сервис.onrender.com/api/orders.xlsx`, но с заголовком X-Admin).

## Важно знать
- **Сервер засыпает.** Бесплатный Render отключается через 15 минут без запросов, первый посетитель ждёт около минуты
  (на сайте покажется «Сервер просыпается…»). Чтобы он не засыпал, настройте бесплатный пинг (например, UptimeRobot) на
  `/api/health` каждые 5 минут. Лимит Render — 750 бесплатных часов в месяц на аккаунт, одного сервиса хватает на круглые сутки.
- Файл `orders.xlsx` на диске не создаётся (диска нет): Excel скачивается кнопкой в админке.
- Кнопки Google Таблиц в админке в этой версии не работают.
- Скидка по промокоду и проверка «один раз на покупателя» считаются в браузере, а не на сервере.
- Резервная копия: в Neon есть история восстановления; можно также сделать экспорт данных из панели Neon.
- Локальная проверка без Neon: в папке `backend` запустите `node --no-warnings server.js` (данные в `backend/data`,
  ключ администратора по умолчанию `dev-admin-key`); сайт откройте любым статическим сервером из `frontend`, а в `config.js`
  укажите `http://localhost:3000`.
